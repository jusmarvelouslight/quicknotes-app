# QuickNotes

## Project Description

QuickNotes is a simple, user-friendly web application that allows users to create, organize, search, and delete notes. It is built using HTML, CSS, and JavaScript. The application uses the browser's local storage to save notes, allowing users to access their saved notes even after refreshing the page.

## Features

- **Create Notes:** Add new notes with a title, content, and category.
- **Organize Notes:** Categorize notes as Personal, School, Work, or Ideas.
- **Search Notes:** Search through notes by title or content.
- **Delete Notes:** Remove notes that are no longer needed.
- **Data Persistence:** Save notes in the browser's local storage so they remain available after refreshing the page.
- **Input Validation:** Ensure required fields are completed before a note is saved.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used

- **HTML5** — Structures the application's content.
- **CSS3** — Styles the interface and provides responsive layouts.
- **JavaScript** — Implements note creation, searching, deletion, validation, and local storage.
- **Browser Local Storage** — Stores notes locally in the user's browser.

## How to Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/jusmarvelouslight/quicknotes-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open the `index.html` file in your web browser.

4. Start creating, searching, and managing your notes.

No additional dependencies or package installation are required for the basic application.

## Limitations

- Notes are stored locally in the browser and are not synchronized across different devices.
- Clearing the browser's site data may remove saved notes.
- The application does not currently use a backend server or user authentication.
